GitHub Pages로 무료 커플 사이트 배포하는 법
  1. GitHub에서 새 저장소(Repository)를 만듭니다 (예: couple-trip).
  2. 이 파일(index.html)을 저장소에 업로드(Commit)합니다.
  3. 저장소 상단 Settings → Pages 메뉴로 이동합니다.
  4. Branch를 main으로 선택하고 Save를 누르면 1분 뒤 나만의 https://아이디.github.io/couple-trip/ 주소가 생성됩니다!
